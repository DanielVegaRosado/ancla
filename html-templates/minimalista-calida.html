{# Warm Minimalist, the HTML counterpart of the `.docx` of the same name: light grey sidebar reaching every page edge with a terracotta accent, main column with a two-line name and each experience as one running paragraph instead of bullets. Only the fields the catalog declares (`docx-templates/README.md`) are used, so the two paths always show the same content. Every section is guarded: a profile with no photo, no education or no languages leaves no empty header behind. The Canva original also has a company address next to each experience and an "Interests" row of icons at the foot of the page — neither field exists on the profile (`Experience.empresa` is always empty, and there is no hobbies catalog), so both are left out rather than faked. The original has no "About me" either; one is added here anyway, right under the headline, because every profile in this app writes one and dropping it would hide real content the user chose to include. #}
